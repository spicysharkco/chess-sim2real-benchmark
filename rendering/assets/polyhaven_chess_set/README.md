# Poly Haven chess set

Piece meshes and textures from [Poly Haven — Chess Set](https://polyhaven.com/a/chess_set),
downloaded through its official file manifest at `https://api.polyhaven.com/files/chess_set`.
The creator is Riley Queen. Poly Haven publishes this asset under
[CC0 1.0 Universal](https://polyhaven.com/license).

This directory contains the 1k glTF package. `downloads.tsv` records the relative filename,
published byte count, published MD5, and exact download URL for every required file. The renderer
uses only the piece nodes; the asset's board node is deliberately excluded so the renderer's
board palette, a1-light parity, and borderless geometry remain unchanged.
