# Omie chess mesh

Source: https://omies-assets.itch.io/3d-chesscheckers-set
Publisher: Omies Assets. Declared licence: CC0 1.0 Universal (verified 2026-09-06).
Archive SHA256: c6737d2f0d8ce5e8011f01bf801346250d61ce060013982722aff3d3f029ff7b

White artist-authored FBX meshes are reused for both neutral material sides.
Source vertices/normals retained, one uniform scale; base aligned, original
textures omitted. FBX v7400 converted using the existing Three.js
triangulation utility. The converter installs no additional packages.
